## How kuro coexists

kuro is installed as its own binary, `kuro`. It does not replace `/usr/bin/vi` and does not read or write any
vim/neovim configuration. To make `vi` open kuro in fish only, see the README ("Install (fish)"); undoing it is
`functions -e vi; rm ~/.config/fish/functions/vi.fish`.

The existing neovim colourscheme is unrelated to kuro: kuro never sets colours of its own beyond the terminal's
16 ANSI palette, so it follows whatever your terminal theme (for example one generated by caelestia) provides.
